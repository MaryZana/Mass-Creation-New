# LLM.txt

Документация дизайн-системы для AI-агентов и IDE.

## Подключение

Укажите в настройках Cursor (или любого другого AI-агента/IDE, поддерживающего документацию) в разделе **Docs** следующую ссылку:

```
https://static-basket-03.wbbasket.ru/vol48/ritmcore/llm.txt
```

Теперь достаточно упомянуть `@Docs ritm` в новом чате, чтобы автоматически подгрузить контекст дизайн-системы.

## Преимущества

- AI лучше понимает код нашей дизайн-системы
- Быстрее помогает с вёрсткой и рефакторингом
- Точнее подсказывает нужные пропсы и меньше «гадает»
- Внутри уже подготовлена база для старта: 20 000 строк кода из Storybook

## Совместимость

`llm.txt` работает не только в Cursor, но и в других средах и агентах, умеющих читать документацию по ссылке: **Copilot**, **Windsurf**, **Zed** и других.

## Локальное использование

Если ваш агент плохо индексирует файлы по ссылке, рекомендуем выгружать `llm.txt` локально через Make-команду:

```makefile
load-ritm-llm: curl -o llm.txt https://static-basket-03.wbbasket.ru/vol48/ritmcore/llm.txt
```

После этого можно тегать сам файл в промпте: `@llm.txt`

Файл может обновляться — следите за обновлениями.

# Ritm Design System Documentation

При работе с React компонентами из Ritm Design System (компоненты с префиксом `Rt*` из пакетов `@dpa/*`) **всегда** используй контекст документации из файла `llm.txt` в корне проекта.

## Важно

- Перед использованием любого компонента Ritm (RtFrame, RtText, RtAvatar и т.д.) обращайся к документации в `llm.txt`
- Следуй примерам и паттернам, описанным в документации
- Используй правильные пропсы и API компонентов согласно документации
- Помни: для верстки с Ritm всегда используй RtFrame и RtText. CSS-variables с цветами нет и их нельзя использовать

## Как использовать

При работе с компонентами Ritm:

1. Открой или прочитай файл `llm.txt` для получения актуальной документации
2. Используй примеры из документации как референс
3. Следуй паттернам использования компонентов, описанным в `llm.txt`

## Пример

​```tsx
// ✅ Правильно — используй документацию из llm.txt для правильного API
import { RtFrame } from "@dpa/react-frame-intro";

// Согласно документации, для создания поверхности используй surface prop
<RtFrame surface="foundation-low-tint" use="generic">
{/_ контент _/}
</RtFrame>;
​```
````
