# Брейкпоинт абстракции

| Название абстракции                                       | Описание                                                                                                                                                                                        | Где доступна           | Возможные значения                                                  |
| --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------- |
| breakpointConfig                                          | Конфиг для определения отрезков breakpoint схемы                                                                                                                                                | RtFrame.Root           | `RtBreakpointConfig`                                                |
| breakpointScheme                                          | Определяет схему коэффициентов масштабирования em-единиц в зависимости от продукта                                                                                                              | RtFrame и RtFrame.Root | `static` — статичная схема без масштабирования, `ritm` — схема ритм |
| isFontSizeProvider                                        | Устанавливать ли на body fontSize. Полезно отключить когда не хотим получить непредсказуемое поведение компонентов не на RITM.                                                                  | RtFrame.Root           | true/false                                                          |
| breakpointXs / breakpointSm / breakpointMd / breakpointLg | Пропс для переопределения breakpoint коэффициентов для блока. Необходимо использовать когда вы хотите отрисовать, например кнопку, на мобильных устройствах также как она выглядит на десктопе. | RtFrame                | `'xs'` \| `'sm'` \| `'md'` \| `'lg'` \| `Record<...>`               |

Брейкпоинты позволяют пропорционально масштабировать компоненты UI kit в зависимости от размеров текущего экрана. Сейчас в дизайн системе есть две брейпоинт схемы `static` и `ritm`. Со следующими коэфициентами масштабирования:

Схема коэфициентов `ritm`:

```json
{
  "ritm": {
    "xs": { "min": 7.25, "default": 7.25, "max": 7.25, "custom": 7.25 },
    "sm": { "min": 7.5, "default": 7.5, "max": 7.5, "custom": 7.5 },
    "md": { "min": 8, "default": 8, "max": 8, "custom": 8 },
    "lg": { "min": 9, "default": 9, "max": 9, "custom": 9 }
  }
}
```

Схема коэфициентов `static`:

```json
{
  "static": {
    "xs": { "min": 8, "default": 8, "max": 8, "custom": 8 },
    "sm": { "min": 8, "default": 8, "max": 8, "custom": 8 },
    "md": { "min": 8, "default": 8, "max": 8, "custom": 8 },
    "lg": { "min": 8, "default": 8, "max": 8, "custom": 8 }
  }
}
```

То есть все компоненты UI kit RITM используют em единицы в CSS:

```css
.test {
  width: 5em;
  height: 5em;
}
```

Значение em, например для экрана `sm.default` рассчитывается следующим образром:

```
5em = 5 * config.currentScheme.currentBreakpoint
5em = 5 * sm.default
5em = 5 * 8
5em = 40px
```

Чтобы выбрать схему укажите в `RtFrame.Root` свойство `breakpointScheme="ritm"`. Эти коэфициенты работают на EM-единицах. То есть в зависимости от текущего брейкпоинта и текущей схемы на документе устанавливается `font-size` за счет которого высчитавается значение em. Границы брейкпоинтов можно определить в `breakpointConfig`.

Если вам не подходит схема, вы можете запросить для своего продукта новую схему с другими коэфициентами.

## breakpointConfig

Конфиг формируется только в RtFrame.Root один раз. Также мы предоставляем `defaultBreakpointConfig`:

```ts
// Если в одном брейкопинт кластере несколько отрезков, то их можно также добавить в min, max или custom.
export const defaultBreakpointConfig: RtBreakpointConfig = {
  xs: {
    min: null,
    default: [0, 767],
    max: null,
    custom: null,
  },
  sm: {
    min: null,
    default: [768, 1279],
    max: null,
    custom: null,
  },
  md: {
    min: null,
    default: [1280, 1920],
    max: null,
    custom: null,
  },
  lg: {
    min: null,
    default: [1921, 5120],
    max: null,
    custom: null,
  },
};
```

Конфиг разделен на кластеры xs, sm, md, lg и на сегменты min, max, default, custom.
В основном используется только default, остальные сегменты нужны для формирования дополнительных кластеров.

## Определение текущего брейкпоинта

Для определения используем `useRtBreakpoint`:

```js
const { xs, sm, xsMin, smDefault } = useRtBreakpoint();
```

## isFontSizeProvider

По дефолту em-единицы работают только внутри ritm компонентов. Для того, чтобы em-единицы начали работать нужно включить `isFontSizeProvider`. Данный пропс устанавливает на body font-size в зависимости от breakpointConfig.

Будьте осторожны включая этот пропс на RtFrame.Root, font-size будет доступен везде, но это может конфликтовать c вашими компонентами, где font-size не установлен или установлен в процентах.

```jsx
<RtFrame.Root isFontSizeProvider>...</RtFrame.Root>
```

Включайте на Root только если уверены в том, что сможете оперативно исправлять сломанный интерфейс или у вас чистый проект. В противном случае можно включить у любого div:

```jsx
<RtFrame isFontSizeProvider>...</RtFrame>
```

**PS. компоненты Ritm UI kit поддерживают em-единицы автоматически и их не нужно оборачивать в** `isFontSizeProvider`

## Альтернатива em-единицам

Вместо em-единиц можно использовать токен `--v0-breakpoint-coefficient`, который не требуется настройки `isFontSizeProvider` и работает схожим образом. Полезно использовать в box-shadow, где em-единицы в сафари криво работают.

## Искусственная подмена текущего брейкпоинта

Также в любом месте DOM-дерева можно руками переключить текущий брейкпоинт. Это нужно, если хотите отрисовать кнопку с брейкпоинта `xs` например в `lg`:

```jsx
<RtFrame breakpointLg="xs">
  <RtButton />
</RtFrame>

// или это равнозначно данной записи:
<RtFrame breakpointLg={{ min: 'xs-min', default: 'xs-default', max: 'xs-max', custom: 'xs-custom' }}>
  <RtButton />
</RtFrame>
```
