# Типографика

```jsx
<RtFrame typographyScheme="secondary" typescale="base" operatorScheme="ritm">
  ...
</RtFrame>
```

- `typographyScheme` — выбор семейства шрифтов, как абстракции
- `typescale` — масштаб текста (на данный момент ничего не меняет)
- `operatorScheme` — слой абстракции операторов, для настройки font-weight типографики и stroke иконок в зависимости от продукта.

#### Как поменять font-family у H1?

```jsx
<RtFrame as="h1" typographyScheme="secondary">
  <RtText as="span" typography="headling-lg-bold">
    Заголовок
  </RtText>
</RtFrame>
```

```jsx
<RtFrame typographyScheme="secondary">
  <RtText as="h1" typography="headling-lg-bold">
    Заголовок
  </RtText>
</RtFrame>
```

PS. в процессе разработки свойство `asChild` для RtFrame, которое не будет создавать html-элементов в разметке.
