# SizeScheme

Абстракция необходима для настройки компонентов RITM ui-kit в зависимости от продукта. При переключении продукта, компоненты меняют CSS-конфиги и меняется их внешний вид (радиусы, отступы, размеры компонентов и тд).

Пример:

```jsx
<RtFrame.Root sizeScheme="wb">...</RtFrame.Root>
```

Или локально:

```jsx
<RtFrame sizeScheme="wb">
  <RtButton label="Добавить продавца" />
</RtFrame>
```
