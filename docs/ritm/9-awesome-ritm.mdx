# Awesome Ritm

Здесь будут расположены community компоненты реализованые на дизайн-системе Ritm другими отделами WB. Данные компоненты не имеют прямой поддежки командой RITM.

## Компоненты

1. [\***\*WB Taxi DataTable\*\***](https://gitlab.wildberries.ru/dashin.ilya/data-table '**WB Taxi  DataTable**') — таблицы с виртуализацией и фильтрами

## Добавление новых компонентов

Есть компоненты, которые могут быть полезны другим командам? Мы будем рады, если вы поделитесь ими через Ritm Awesome.

\***\*Требования для добавления:\*\***

- Компонент должен находиться в отдельном публичном репозитории GitLab
- Компонент должен быть доступен для установки через npm

Для добавления компонента свяжитесь с isakov.ilya5
